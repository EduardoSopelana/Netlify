# Proyecto Netlify - Pokémon Web

Este proyecto es una página web estática centrada en la temática de Pokémon, diseñada para ser desplegada en **Netlify**[cite: 1].

## Estructura del Proyecto

El repositorio contiene los siguientes archivos y recursos:
* **`index.html`**: Página principal del sitio web[cite: 1].
* **`style.css`**: Hoja de estilos para la maquetación y diseño visual[cite: 1].
* **`img/`**: Carpeta que incluye recursos gráficos de Pokémon, tales como:
  * `blastoise.png`[cite: 1]
  * `bulbasur.png`[cite: 1]
  * `charizard.png`[cite: 1]
  * `gengar.png`[cite: 1]
  * `squirtle.png`[cite: 1]

## Despliegue

Este proyecto está optimizado para alojarse de forma rápida y sencilla en la plataforma [Netlify](https://www.netlify.com/)[cite: 1].
